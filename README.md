# 🛒 Flipkart Sales Data Analysis (Excel Project)

## 📌 Project Overview
This project focuses on analyzing Flipkart sales data using Microsoft Excel. The main objective is to extract meaningful insights from raw e-commerce data and create an interactive dashboard for better business decision-making.

The project covers data cleaning, data analysis, and visualization techniques to understand sales performance, customer behavior, and product trends.

---

## 🎯 Objectives
- Analyze overall sales and revenue performance
- Identify top-performing products and categories
- Understand customer ratings distribution
- Track sales trends over time
- Build an interactive dashboard using Excel

---

## 🛠 Tools & Features Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers & Filters
- Conditional Formatting
- SUM, SUMIF, COUNT, COUNTIF, AVERAGE Functions
- Data Cleaning Techniques
- Dashboard Design

---

## 📊 Key Analysis Performed
- Total Sales & Revenue Calculation
- Category-wise Sales Analysis
- Top 10 Products by Revenue
- Customer Rating Analysis
- Order Count & Performance Metrics
- Trend Analysis using Charts

---

## 📈 Dashboard Features
- Interactive slicers for filtering data
- Dynamic KPI cards (Total Sales, Orders, Revenue)
- Category-wise comparison charts
- Clean and professional layout
